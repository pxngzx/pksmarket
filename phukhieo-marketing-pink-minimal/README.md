# โรงเรียนภูเขียว - Phukieo Marketing (Minimal Pink & White Edition)

เว็บไซต์โรงเรียนภูเขียว ออกแบบในโทน **ชมพู-ขาว มินิมอล (Pink & White Minimal)**

## 🌸 คุณสมบัติเว็บ:
- **โทนสี & ดีไซน์**: ชมพู-ขาว ละมุน ตกแต่งด้วยพื้นหลังลายตาราง (Grid Background)
- **อนิเมชันสวยงาม**: มีอนิเมชันดอกไม้ร่วง (Falling Petals) และดาวประดับวิบวับทั่วหน้าเว็บ
- **ระบบแอดมิน (Admin Passkey)**: `PKstudent_mk`

## 📁 รายชื่อไฟล์:
- `index.html` : หน้าแรกของเว็บไซต์
- `admin.html` : หน้าจัดการแอดมิน (เข้าด้วยรหัส `PKstudent_mk`)
- `product.html` : หน้าแสดงรายละเอียดสินค้า/ผลงาน
- `my-products.html` : หน้าผลงานของฉัน
- `search.html` : หน้าค้นหา
- `css/style.css` : สไตล์การตกแต่งมินิมอลชมพู-ขาว
- `js/app.js` : ระบบอนิเมชันดอกไม้ร่วงและสคริปต์การทำงาน
